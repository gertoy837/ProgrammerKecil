# BettaVerse

BettaVerse adalah website toko online sederhana yang terdiri dari backend API dan frontend React.

## Deskripsi Website

Website ini dirancang untuk menampilkan katalog produk, detail produk, keranjang belanja, autentikasi user, dan fitur admin untuk mengelola data produk serta kategori. Backend menangani data, login, JWT, database MySQL, dan upload file. Frontend dibangun dengan React dan digunakan untuk menampilkan halaman-halaman aplikasi secara interaktif.

## Fitur Utama

- Katalog produk
- Detail produk
- Keranjang belanja
- Register dan login user
- Autentikasi dengan JWT
- Admin dashboard untuk kelola produk dan kategori
- Upload gambar produk/kategori

## Struktur Project

- `backend/` untuk API server, database, middleware, dan controller
- `frontend/` untuk tampilan website berbasis React

## Cara Menjalankan Project

Jalankan dari folder utama:

```bash
npm run dev
```

Perintah ini akan menjalankan backend dan frontend secara bersamaan.

## Teknologi yang Digunakan

- React
- Vite
- Express.js
- MySQL
- JWT
- Axios
- Multer

## Catatan

- Backend berjalan di `http://localhost:5000`
- Frontend berjalan di `http://localhost:5173`
